# Altron Studio

Altron Studio is a full-stack web application developed using **Angular** for the frontend and **Java** for the backend. The project demonstrates modern web development practices with a responsive user interface, efficient API integration, and scalable architecture.

## Features

* Responsive and modern user interface
* Angular-based frontend application
* Java backend for business logic and API handling
* Clean and maintainable code structure
* Fast and user-friendly experience

## Technologies Used

* Angular
* TypeScript
* HTML5
* CSS3
* Java
* REST APIs

## Live Demo

https://altron-studio.web.app/

## Installation

### Frontend

```bash
npm install
ng serve
```

### Backend

```bash
# Run the Java Spring Boot application
mvn spring-boot:run
```
